# Raccourcis clavier

Sur Windows et Linux, remplace `Cmd` par `Ctrl`.

---

## Navigation globale

| Action | macOS | Win/Linux |
|---|---|---|
| Quick switcher (notes, entités, actions) | `Cmd+K` | `Ctrl+K` |
| Recherche full-text avancée | `Cmd+Shift+F` | `Ctrl+Shift+F` |
| Knowledge graph | `Cmd+G` | `Ctrl+G` |
| Nouvelle note | `Cmd+N` | `Ctrl+N` |
| Fermer l'onglet actif | `Cmd+W` | `Ctrl+W` |
| Onglet suivant | `Cmd+]` | `Ctrl+]` |
| Onglet précédent | `Cmd+[` | `Ctrl+[` |
| Settings | `Cmd+,` | `Ctrl+,` |
| Capture rapide (global, hors Supernote) | `Cmd+Shift+Space` | `Ctrl+Shift+Space` |
| Ouvrir l'Inbox | `Cmd+Shift+I` | `Ctrl+Shift+I` |
| Journal du jour | `Cmd+Shift+D` | `Ctrl+Shift+D` |
| Focus sidebar | `Cmd+Shift+E` | `Ctrl+Shift+E` |
| Masquer/afficher sidebar | `Cmd+\` | `Ctrl+\` |
| Masquer/afficher panneau droit | `Cmd+Shift+\` | `Ctrl+Shift+\` |
| Recharger | `Cmd+R` | `Ctrl+R` |

## Editeur — Blocs

| Action | macOS | Win/Linux |
|---|---|---|
| Slash menu (insérer bloc) | `/` | `/` |
| Titre 1 | `# ` + espace | idem |
| Titre 2 | `## ` + espace | idem |
| Titre 3 | `### ` + espace | idem |
| Liste à puces | `- ` + espace | idem |
| Liste numérotée | `1. ` + espace | idem |
| Checklist | `[ ] ` + espace | idem |
| Citation | `> ` + espace | idem |
| Bloc de code | ` ``` ` + Enter | idem |
| Toggle | `/toggle` | idem |
| Callout | `/callout` | idem |
| Nouveau bloc (Enter) | `Enter` | `Enter` |
| Supprimer bloc vide (Backspace) | `Backspace` | `Backspace` |
| Déplacer bloc vers le haut | `Cmd+Shift+↑` | `Ctrl+Shift+↑` |
| Déplacer bloc vers le bas | `Cmd+Shift+↓` | `Ctrl+Shift+↓` |

## Personnaliser les raccourcis

Settings > Raccourcis : tu peux remapper n'importe quel raccourci listé ci-dessus ou créer un raccourci personnalisé vers une routine, une vue, ou une commande de plugin.
